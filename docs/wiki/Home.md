# Welcome to Rill

A local API workbench for macOS, with a native app and a CLI sharing the same execution engine. No account or hosted workspace is required.

## Start here

- [Download Rill 0.4.5](https://github.com/alby-raju/Rill/releases/tag/v0.4.5-dev.1). Requires macOS 15+, Apple Silicon or Intel. Builds are ad-hoc signed, not Developer ID signed or notarized.
- [Workbench quick start](https://github.com/alby-raju/Rill/wiki/Workbench-Quick-Start) covers request selection, workspace tools, and Cookie Manager.
- [CLI quick start](https://github.com/alby-raju/Rill/wiki/CLI-Quick-Start): use the CLI included in the installed app.
- [Local mock server](https://github.com/alby-raju/Rill/wiki/Local-Mocks): find the existing app tool and CLI command.
- [Roadmap](https://github.com/alby-raju/Rill/wiki/Roadmap): CLI-first priorities and cross-platform plans.
- [Contributing and support](https://github.com/alby-raju/Rill/wiki/Contributing-and-Support).

## Current capabilities versus future plans

The [feature guide](https://github.com/alby-raju/Rill/blob/main/docs/FEATURES.md) documents what is supported today. The [roadmap](https://github.com/alby-raju/Rill/blob/main/ROADMAP.md) describes planned enhancements, not released behavior. Rill 0.4.5 can run supported Postman and native collection files from the CLI. Imported Postman JavaScript remains outside the supported execution subset.

For synthetic endpoints and sample collections, use the [verification kit](https://github.com/alby-raju/Rill/tree/main/verification). Do not upload internal API collections, credentials or private certificate keys to public issues or discussions.

This Wiki is a navigation and onboarding layer. Detailed command behavior, limitations and acceptance evidence live in the versioned repository docs.
