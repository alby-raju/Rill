# What comes next

**[Read the prioritized roadmap](https://github.com/alby-raju/Rill/blob/main/ROADMAP.md)** · [Suggest priorities](https://github.com/alby-raju/Rill/discussions)

Rill's next focus is CLI-first API testing:

1. Direct collection/environment file runs, temporary variables and headless TLS.
2. Explicit script compatibility, reliable workflow semantics and better failure reports.
3. A first-class mock workbench using the existing mock engine.
4. Measured responsiveness, efficient execution and useful run comparisons.
5. Linux CLI delivery, followed by native Windows CLI work.
6. A separate desktop portability decision after platform and user-demand evidence.

All these enhancements are planned; inclusion does not mean implementation has started or that a release date is promised. The repository roadmap holds task IDs, acceptance criteria, status, performance measurement rules and cross-platform effort estimates. Do not use this summary as a compatibility declaration.

Share the workflow you cannot complete today, the smallest sanitized reproduction and the outcome you need. Vote with reactions or describe your use case in Discussions. Confirmed bugs and implementation tracking belong in [Issues](https://github.com/alby-raju/Rill/issues). Do not post private API details or credentials.
