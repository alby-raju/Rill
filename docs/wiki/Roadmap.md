# What comes next

**[Read the prioritized roadmap](https://github.com/alby-raju/Rill/blob/main/ROADMAP.md)** · [Suggest priorities](https://github.com/alby-raju/Rill/discussions)

Rill's next focus is CLI-first API testing:

1. Finish CLI acceptance and add final-environment export. Direct file runs, temporary variables, iteration data, and scoped file-based TLS are available in 0.4.5.
2. Explicit script compatibility, reliable workflow semantics and better failure reports.
3. A first-class mock workbench using the existing mock engine.
4. Measured responsiveness, efficient execution and useful run comparisons.
5. Linux CLI delivery, followed by native Windows CLI work.
6. A separate desktop portability decision after platform and user-demand evidence.

The roadmap distinguishes available increments from planned enhancements. The repository roadmap holds task IDs, acceptance criteria, status, performance measurement rules and cross-platform effort estimates. Do not use this summary as a compatibility declaration.
