# M3: Interchange and generated clients

Status: in progress. Implementation is independent of the original archive. Foreign formats and generated client targets are tracked separately; no universal compatibility is claimed.

## Slice 1: Native import plans

IO-01/08: native import now prepares and validates an immutable plan before showing collection/request/environment/auth/TLS/secret-descriptor counts, request names and specific warnings. Cancel applies no incoming data. Auth values are discarded; identities are regenerated; collisions, file-reference handling, local/process references, insecure TLS and client-identity reselection are disclosed. No referenced file is read and no network request is sent by preview.

Apply verifies that saved user data still matches the preview baseline while preserving new session-only exchanges. It then atomically commits the complete bounded native workspace before publishing it to the UI. Native imports contain fresh request identities with no credentials, so this path needs no Keychain writes and cannot fail after a metadata commit because a companion credential deletion was denied. Existing secrets stay unchanged. External/stale file revisions still reject the commit. Existing pending structural edits are flushed before building the preview; separate request drafts remain untouched.

Five new tests bring the suite to 112 cases: preview warnings/counts without mutating input or exposing seeded credentials, stale user edits versus preserved session activity, pure import under denied companion writes, concurrent external import protection and invalid-plan/export destination preservation. Installed-app preview/cancel/apply and disk-permission failure checks remain pending. IO-01/08 remain partial; foreign formats and shell/snippet paths are subsequent slices.
