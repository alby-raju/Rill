# Bounded native hook interpreter (2026-10-24)

Rill's initial opt-in hook language is `json-operations-v1`, an independently authored, finite JSON operation tree. It is deliberately a documented native API rather than JavaScript compatibility. Foreign JavaScript stays disabled review text and cannot become an enabled hook by import. Native imports also disable executable hook flags until the user reviews/enables them.

There is no third-party runtime or parser dependency: Foundation JSON decoding and CryptoKit ship with supported macOS 14+ on Intel and Apple Silicon. Apple maintains these platform frameworks; no extra runtime license, notice, downloaded executable or app resource is introduced. Review date 2026-10-24. Platform updates supply security fixes; no claim of a comprehensive vulnerability audit or OS sandbox is made.

The grammar supports finite conditionals, variable get/set/unset through templates, request URL/body/header updates, response status/header/body reads, assertions, extraction, branch/stop, bounded logs and offline SHA-256/HMAC-SHA256/time/UUID helpers. It has no loops, recursion, functions, evaluation, imports, host bridge, network, filesystem, process or environment APIs. Unknown operations, including loop/eval/JavaScript source, fail validation. A static operation/depth limit plus an execution deadline, cancellation checks and input/variable/log/output budgets constrain work. Infinite programs cannot be represented; they are rejected before execution rather than entrusted to a cooperative JavaScript interrupt.

Inputs and outputs are value copies: failed hooks do not publish variable/request/branch changes. Logs never enter exported reports by default. The interpreter cannot read named secrets directly; users may deliberately supply run-local values for signing, which are kept out of reports. Request signing over an opaque Keychain token is not claimed. Future general-purpose language support requires a separately reviewed helper-process isolation design with hard process termination and measured memory bounds; do not silently add eval to this interpreter.

Removal or upgrade changes only optional hook metadata and the interpreter; native hook language identity must remain versioned. Imported script review material is independent and remains plain text.
