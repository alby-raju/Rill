# Native event protocol dependencies

2026-10-24 selection, before adding runtime dependencies. No original Relay code, JAR, fixtures or protocol dependencies are reused.

MQTT 3.1.1/5 and AMQP 0-9-1 use independently authored bounded packet codecs and Apple's Network framework; MQTT WebSocket transport reuses Rill's independently authored native live connection. Both use system trust/hostname verification and no automatic reconnect, redirect, topology creation or plugin loading. Current mqtt-nio requires Swift 6.2.3 and a broader NIO configuration/tracing graph; the bounded workbench subset instead keeps these transports native. This requires explicit independent-broker acceptance beyond synthetic fixtures; full MQTT extension/AMQP topology coverage is not claimed.

For gRPC select official grpc-swift-2 2.4.4, grpc-swift-nio-transport 2.11.0 and SwiftProtobuf 1.39.0, exact pins. Upstream manifests/licenses and public GitHub security-advisory endpoints were checked on this date; those three repositories returned no published advisories. This is a point-in-time review, not a claim of vulnerability absence. Resolve/pin transitive versions, retain their licenses/notices and privacy manifests, and validate each architecture before merge. Also select swift-server/swift-kafka-client 1.0.0-beta.1 (native librdkafka wrapper), exact pin. Its public advisory endpoint returned no published advisories. It is a beta API: keep the adapter isolated, disable offset commits and await delivery reports. Verify the vendored C/TLS/compression dependency graph and retain all associated notices; no system OpenSSL, JVM or JAR may be required. Kafka and gRPC use Apache 2.0; SwiftProtobuf uses Apache 2.0 with its runtime-library exception. Prefer the TransportServices product for system-native TLS; avoid loading old compatibility binaries or an external grpcurl process.

Current Protobuf requires Swift 6.2. Build minimum/CI must move accordingly rather than hiding an old parser pin behind a newer SDK. The user chose macOS 15+ for the complete application on 2026-10-24. Both gRPC Swift 2 and the Kafka client require macOS 15; Swift 6.2.3 is the new build minimum. CI retains Intel and Apple Silicon and moves to Xcode 26.2/26.3. Protobuf descriptor handling must validate untrusted inputs before constructing any plugin-library descriptor graph with preconditions. Source compilation must use a separately built and bundled official compiler for the target architecture with bounded process input/output/time/cancellation, explicit imports and retained notices; never invoke a shell or a user-specified plugin implicitly.
